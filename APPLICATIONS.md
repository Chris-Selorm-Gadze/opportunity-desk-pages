# Private application records (branch: applications-private)

This branch is NOT published by GitHub Pages (Pages serves only `main`).
It will hold Selorm's application records (stage, dates, notes per catalog
opportunity id, using the dashboard's own stage vocabulary) once the
repository is private.

Until the repo is switched to private, this file stays empty of real
records — application data lives only in Muse's private tracker.
Never merge this branch into `main`, and never copy these records into
catalog.json (the public catalog contract forbids application records).
