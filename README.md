# Opportunity Desk — GitHub Pages

Live dashboard: https://chris-selorm-gadze.github.io/opportunity-desk-pages/

The public catalog combines the original collection with daily travel/leadership and trading/finance tasks, twice-daily finance/internship discovery, plus an hourly connected-spreadsheet sync. It loads on opening, when the page becomes visible, every five minutes while visible, and with Refresh. Daily updates shows research freshness and recent changes. Daily publishing uses Codex and the existing Git access on this computer; keep local execution available at the scheduled times (finance/internships: 9 AM and 3 PM America/Chicago). See [CATALOG.md](CATALOG.md) for the data-only publishing contract.

Sections, category filters, finance filters, calendar months and opportunity details have URL routes with browser Back/Forward support. Existing #finance links still work. The Finance & tech view focuses on U.S. work locations, including remote roles explicitly available from the U.S. Foreign-only discovery listings are hidden while existing application history remains saved. Multi-country programs are shown for their U.S. options only. The view separates technology/audit and banking/investment roles, shows sponsorship evidence and graduation ranges, and tracks application stages and follow-ups. Application notes, checklists and preferences save only in your browser. Catalog merges preserve your progress, ratings and personal dates; source edits that conflict are held for review. Use JSON backup export/restore to move between devices.

Calendar exports include reminders; enable alerts in your calendar application and export again after changes. The separate cloud deadline watch cannot read this browser’s saved status.

This repository contains public website assets and public opportunity facts. Never commit application records, credentials, task prompts or personal profiles.
